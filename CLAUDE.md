# Keycloak GraphQL API Implementation Plan

## Overview
Implement Keycloak-style functionality using GraphQL (gqlgen, schema-first) integrated into the existing shadow-sso service. Single realm only (no multi-realm).

## Features
- Full user management
- Client/OAuth application management  
- Token management & introspection
- Role management
- Token mappers
- Identity provider federation
- Session management
- Authentication flows
- Group management
- Realm settings

## Implementation Steps

### Step 1: Add gqlgen dependency and generate (priority: high)
- Add `github.com/99designs/gqlgen` to go.mod
- Create `graphql/schema.graphqls` with complete Keycloak-style schema
- Run `gqlgen generate` to generate Go types

### Step 2: Create GraphQL schema (priority: high)
Design schema covering:
- Queries: users, clients, roles, sessions, identityProviders, groups, realm
- Mutations: create/update/delete users, clients, roles, groups, etc.
- Types: User, Client, Role, Group, IdentityProvider, TokenMapping, Session

### Step 3: Implement resolvers (priority: high)
- Create resolver implementations wired to existing domain repositories
- Leverage existing MongoDB repositories where possible
- Add new repositories for missing domain types (groups, token mappers)

### Step 4: HTTP server integration (priority: high)
- Add GraphQL HTTP handlers to existing ssso service
- Use `/graphql` endpoint path
- Add playground for development

### Step 5: Authentication & Authorization (priority: high)
- JWT-based authentication for GraphQL API
- Role-based access control for mutations
- Support API key authentication for service accounts

## GraphQL Schema Draft

```graphql
type Query {
  users(filter: UserFilter): [User!]!
  user(id: ID!): User
  clients(filter: ClientFilter): [Client!]!
  client(id: ID!): Client
  roles: [Role!]!
  groups: [Group!]!
  sessions: [Session!]!
  identityProviders: [IdentityProvider!]!
  realm: RealmSettings!
  tokenIntrospect(token: String!): TokenIntrospection!
}

type Mutation {
  # User management
  createUser(input: CreateUserInput!): User!
  updateUser(id: ID!, input: UpdateUserInput!): User!
  deleteUser(id: ID!): Boolean!
  resetPassword(userId: ID!, newPassword: String!): Boolean!
  
  # Client management
  createClient(input: CreateClientInput!): Client!
  updateClient(id: ID!, input: UpdateClientInput!): Client!
  deleteClient(id: ID!): Boolean!
  
  # Role management
  createRole(input: CreateRoleInput!): Role!
  updateRole(id: ID!, input: UpdateRoleInput!): Role!
  deleteRole(id: ID!): Boolean!
  
  # Group management
  createGroup(input: CreateGroupInput!): Group!
  updateGroup(id: ID!, input: UpdateGroupInput!): Group!
  deleteGroup(id: ID!): Boolean!
  
  # Identity Provider
  createIdentityProvider(input: CreateIdentityProviderInput!): IdentityProvider!
  updateIdentityProvider(id: ID!, input: UpdateIdentityProviderInput!): IdentityProvider!
  deleteIdentityProvider(id: ID!): Boolean!
  
  # Realm settings
  updateRealmSettings(input: UpdateRealmSettingsInput!): RealmSettings!
  
  # Session management
  revokeSession(sessionId: ID!): Boolean!
  revokeAllSessions(userId: ID!): Boolean!
}
```
